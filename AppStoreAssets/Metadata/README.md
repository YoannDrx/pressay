# Métadonnées App Store Connect

Le dossier `up-6795505605` contient les textes français de Pressay 1.2.0 tels qu’ils sont publiés dans App Store Connect.

La mise à jour s’effectue avec `xcrun altool --app-store-text AppStoreAssets/Metadata --upload --apple-id 6795505605 --bundle-short-version-string 1.2.0 --platform macos`, en ajoutant l’authentification App Store Connect et le provider public `89ebbfb5-6043-4aae-b6c6-fb1b447b1f38`.

Les captures prêtes à charger sont dans `AppStoreAssets/Screenshots/Final`.
