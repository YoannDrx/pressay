## Pressay 1.2.7

Cette mise à jour rend le compte Pressay autonome et fiabilise la connexion de
l’application macOS.

### Identité Pressay auto-hébergée

- Clerk est remplacé par Better Auth hébergé avec Pressay et Neon.
- La connexion Google reste disponible sans abonnement Clerk.
- L’espace compte permet d’ajouter une passkey Touch ID, d’activer TOTP, de
  gérer les codes de secours et de révoquer les sessions web.
- Les opérations administratives sensibles exigent une validation TOTP récente.

### Connexion macOS sécurisée

- Pressay utilise désormais OAuth 2.1 Authorization Code avec PKCE et une
  audience API explicite.
- Les jetons d’accès expirent après quinze minutes ; les jetons de
  renouvellement tournent à chaque utilisation et peuvent être révoqués.
- Les builds déjà installés conservent le même identifiant client et le même
  callback `pressay://oauth/callback`.

### Codes, parrainage et facturation

- Un code d’accès complète le droit effectif sans raccourcir un abonnement
  Stripe actif et ne se consomme que s’il améliore réellement l’accès.
- Le parrainage attribue les deux récompenses uniquement après un premier
  paiement éligible et les annule après remboursement complet.
- Les campagnes, reprises et remboursements restent tracés dans l’audit admin.

### Validation

- 140 tests Swift, 31 tests API et les parcours staging desktop/mobile ont été
  exécutés avant publication.
- Google OAuth, TOTP admin, code d’accès, parrainage, paiement test,
  remboursement, PKCE, renouvellement et révocation ont été validés en réel.
